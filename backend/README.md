# Backend structure

This directory is scaffolded for the planned hotel-management API. Files marked as placeholders contain no implementation yet.

The current working API is in `src/server.ts`; MongoDB connection and Mongoose models are in `src/db/`. The planned modular files are scaffolding only and are not yet connected to the running API.

Configure `backend/.env` from `.env.example` before running the API. Do not commit `.env` or add credentials to source control.
